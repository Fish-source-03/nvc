# 问题清单索引

> **来源**：对照《系统详细设计说明书》与《项目复盘报告》，对 13 个 `agent-qr-*` 模块的逐类逐方法一致性核查
> **核查日期**：2026-10-06
> **核查方式**：全部为**静态代码分析**（未编译、未启动服务、未连接数据库、未发起请求）
> **组织方式**：一个问题一个文档，每份文档包含「问题描述 + 推断依据（含 `文件:行号` 证据）+ 影响范围 + 修复方向 + 核查边界」

## 使用说明

- 每份文档的**推断依据**部分给出可直接跳转的 `文件路径:行号`，便于逐条复核。
- **核查边界**部分明确标注了该结论未验证的部分（多为运行时行为），实施修复前建议先按该节做验证。
- 本文档集**未修改任何源码或配置**，仅为核查记录。

## 四、跨问题的共性模式

核查发现一个反复出现的模式，贯穿上述多个问题：**"文档有、代码有、运行时不生效"**。具体表现为四类：

| 模式 | 实例 |
|---|---|
| **声明存在但运行不生效** | [01](01-定时任务全线失活.md) 缺 `@EnableScheduling`；[05](05-CQRS读写分离不生效.md) 无 `readOnly=true`；[16](16-EmbeddingDimensionManager为死代码导致Collection隔离不生效.md) 调用链断开 |
| **空壳实现** | [02](02-DLQ重试链路失效.md) 四个 retry 方法；[10](10-PDF表格结构化保留为空实现.md) `return null`；[25](25-CharsetDetector编码检测与转码形同虚设.md) 回退循环恒真；[31](31-DocumentDeleteServiceV2在ChromaRetriever为空时假成功.md) 空依赖假成功 |
| **死配置 / 死代码** | [38](38-配置项与代码实现脱节.md) 10 个**误导性**配置键（注释声称生效、实际无读取点）；[14](14-RerankerService静默降级为非交叉编码器实现.md) 模型配置未使用；[15](15-BM25Retriever未升级为磁盘索引与异步构建.md) 预留线程池无消费者 |
| **契约错配** | [33](33-前后端契约断裂.md) 4 处参数被静默丢弃；[02](02-DLQ重试链路失效.md) 事件类型不一致；[18](18-RRF融合去重键跨路不一致.md) 跨路标识语义不同 |

这与复盘报告 §3 问题 1（"任务形式上完成但需求未落地"）是同一根因在不同层面的表现。报告只覆盖了"需求→任务"环节的损耗，**"文档→实现"环节的回填缺失**是未被识别的下游问题（见 [39](39-设计文档内部矛盾与实现脱节.md)）。
